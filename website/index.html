0 Config Required

No log shippers or databases. Just wrap your existing startup command (e.g. logsight run -- python app.py) and LogSight intercepts everything automatically.

Real-Time ML

Uses an unsupervised Isolation Forest model from scikit-learn to score logs in real-time, instantly surfacing anomalies without requiring manual rules.

Premium Dashboard

A beautiful dark-mode glassmorphism UI served directly to your browser on port 5000. Features streaming tails, severity distribution charts, and critical alerts.
