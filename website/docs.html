Documentation

Welcome to the official LogSight documentation. Learn how to bring enterprise-grade Machine Learning log analytics directly to your local development environment with zero configuration.

Installation

LogSight is published on PyPI and can be installed globally using pip. Python 3.8+ is required.

pip install logsight

Run Mode (Wrapper)

Run Mode is the easiest way to use LogSight. You simply prepend logsight run to whatever command you normally use to start your application.

Because LogSight acts purely as a wrapper around the standard output, you can run it on any application without making any code changes or configuration updates.

# Wrap a Python/FastAPI app
logsight run uvicorn app.main:app --reload

# Wrap a React/Next.js/Node app
logsight run npm run dev

# Wrap a Docker Compose stack
logsight run docker-compose up

Watch Mode (Tail)

If your application already writes logs to a file (or multiple files) instead of standard output, LogSight can simply tail those files in the background.

logsight watch path/to/application.log path/to/auth.log

ML Anomaly Detection

LogSight uses an unsupervised Machine Learning pipeline based on an Isolation Forest algorithm from scikit-learn.

It automatically extracts features from your logs such as log levels, text characteristics, and the rate of generation. The model is pre-trained offline on diverse datasets (including OpenStack backend server logs and popular frontend framework outputs) and scores your logs in real-time. The higher the anomaly score, the more unusual the log event is compared to standard system traffic.

Secret Scrubbing

Since LogSight runs locally, it is inherently secure. However, to prevent you from accidentally sharing screenshots or pasting logs that contain sensitive data, LogSight automatically scrubs standard secret patterns.

It will redact things like AWS Credentials (AKIA...), JWTs, API Keys, and passwords from your terminal and dashboard.

The Dashboard

Whenever you start LogSight, it automatically spins up a background Flask server on port 5000 and opens your browser to the beautiful, dark-mode dashboard.

The dashboard provides:

  • Live streaming log tailing.
  • Severity distribution and anomaly scoring over time.
  • Top noisy services charts.
  • Critical alert feeds with visual cues.
